Input selection takes a final `spend_authority: &SpendAuthority<AccountId>` argument: `InputSource::{select_spendable_notes, select_single_spendable_note, get_spendable_transparent_outputs, get_spendable_transparent_outputs_for_addresses, select_spendable_transparent_outputs}`, `wallet::input_selection::InputSelector::propose_transaction`, `ShieldingSelector::{propose_shielding, propose_shielding_coinbase}`, and `wallet::{propose_transfer, propose_standard_transfer_to_address, propose_send_max_transfer, propose_shielding, propose_shielding_coinbase}`. `WalletRead::{get_wallet_summary, get_transparent_balances}` take the same argument and report unauthorized value as watch-only. `wallet::shield_transparent_funds` derives authority from its `SpendingKeys`.

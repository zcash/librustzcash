`zcash_primitives::transaction`:
- `Transaction` is now `Transaction<A: Authorization = Authorized>`. Immutable
  data access, `txid`, and `into_data` support both authorized and effects-only
  transactions. Complete reading, writing, and authorization commitments
  remain restricted to `Transaction<Authorized>`.
- `TransactionDigest::{digest_sapling, digest_orchard, digest_ironwood}` return `Result`.
- `TransactionData::map_authorization` requires equal source and destination
  anchor representations. Use `map_bundles` with the protocol anchor mappers
  when changing that representation.

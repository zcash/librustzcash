`pczt::roles::creator::Error::AnchorRequiredForV5`, which was unreachable since its introduction. `Creator::new`'s documentation now matches the tested behavior: for v5 transactions an anchor may be absent while the corresponding bundle is empty (a v5 transaction only carries `anchorSapling` for a bundle with Sapling spends, and `anchorOrchard` for a bundle with any actions); it must be set by the time the bundle gains spends or actions, which the anchor requirement of the role consuming the PCZT enforces.

`pczt::roles::signer::Signer::shielded_sighash` returns `Result<[u8; 32], Error>`.
For V7 it returns `Error::NoSharedShieldedSighash`; use `sapling_sighash`,
`orchard_sighash`, or `ironwood_sighash` instead.
V7 transparent signing and spend finalization accept only `SIGHASH_ALL`,
even when the configured policy allows other sighash types.
